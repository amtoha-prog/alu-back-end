# API

Python scripts that fetch employee TODO data from the
[JSONPlaceholder](https://jsonplaceholder.typicode.com) REST API and export it.

| File | Description |
| --- | --- |
| `0-gather_data_from_an_API.py` | Prints an employee's TODO progress and completed task titles |
| `1-export_to_CSV.py` | Exports an employee's tasks to `USER_ID.csv` |
| `2-export_to_JSON.py` | Exports an employee's tasks to `USER_ID.json` |
| `3-dictionary_of_list_of_dictionaries.py` | Exports all employees' tasks to `todo_all_employees.json` |

Usage: `./0-gather_data_from_an_API.py 2`
